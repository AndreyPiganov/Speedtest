# Speedtest

Консольный скрипт на Node.js для измерения скорости скачивания с указанного HTTP- или HTTPS-адреса.

Скрипт выполняет **10 последовательных GET-запросов**. Каждый следующий запрос начинается только после полного чтения тела предыдущего ответа. После завершения выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

Node.js **22 или новее**. Внешних зависимостей нет, выполнять `npm install` не нужно.

## Запуск

```bash
git clone https://github.com/AndreyPiganov/Speedtest.git
cd Speedtest
node speedtest.js "https://example.com/large-image.jpg"
```

Замените адрес на прямую ссылку на существующий файл. URL с параметрами передавайте в кавычках.

Также можно запустить через npm:

```bash
npm start -- "https://example.com/large-image.jpg"
```

Справка: `node speedtest.js --help`.

Пример вывода (значения условные; промежуточные строки сокращены):

```text
Запрос 1/10: 200.00 мс, 1048576 байт
...
Запрос 10/10: 200.00 мс, 1048576 байт

Среднее время запроса: 200.00 мс
Всего скачано: 10485760 байт (10.00 МиБ)
Скорость скачивания: 5.00 МиБ/с
```

## Как считаются результаты

- Время измеряется монотонными часами от начала запроса до получения всего тела ответа, включая установление соединения и ожидание ответа сервера. Единица — **миллисекунда (мс)**.
- Среднее время = сумма длительностей 10 запросов / 10.
- Общий объём — сумма фактически прочитанных байтов тел 10 успешных ответов. Заголовки HTTP и служебный сетевой трафик не учитываются. `Content-Length` для подсчёта не используется.
- Скорость = общий объём / суммарное время запросов. Единица — **мебибайт в секунду (МиБ/с)**, где 1 МиБ = 1 048 576 байт. Это отношение суммарного объёма к суммарному времени, а не среднее отдельных скоростей.

Ответ читается потоком и не сохраняется на диск или целиком в памяти. Скрипт запрашивает несжатый ответ (`Accept-Encoding: identity`); если сервер всё же применяет сжатие, учитывается размер сжатого тела без распаковки. Встроенного кеширования ответов нет.

Поддерживаются до 5 перенаправлений (301, 302, 303, 307, 308) для каждой загрузки, включая относительные адреса. Перенаправления создают дополнительные HTTP-запросы; время всей цепочки входит в замер, а объём учитывается только для конечного ответа.

Лимит времени одной загрузки — **60 секунд**, включая перенаправления и чтение всего тела. При некорректном адресе, сетевой ошибке, обрыве ответа, превышении лимита или статусе вне 2xx (кроме поддерживаемых перенаправлений) скрипт пишет ошибку в stderr и завершается с кодом `1`. Итоговая статистика незавершённой серии не выводится. Успешный запуск и справка завершаются с кодом `0`.

Измерение отражает скорость загрузки с выбранного сервера с учётом задержек; результат зависит от размера файла, сервера и сетевого соединения.

## Проверка

```bash
npm test
```

Тесты используют встроенный `node:test` и локальный HTTP-сервер, доступ в интернет не требуется. Проверяются последовательность 10 загрузок, ожидание полного тела ответа, подсчёт байтов и итогов, перенаправления и обработка ошибок.
